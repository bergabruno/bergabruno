Senior Software Engineer at **Bradesco**, one of Brazil's largest financial institutions. Focused on building scalable, resilient, and maintainable back-end systems. Passionate about clean architecture, microservices, and cloud-native solutions.

- Currently working at **Bradesco** on high-availability financial systems
- MBA in Software Engineering at **FIAP**
- **AWS Certified** and **Azure** certified professional
- Advocate for Clean Code, SOLID principles, and Domain-Driven Design
